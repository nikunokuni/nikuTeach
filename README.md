# nikuTeach — オンライン家庭教師アプリ

先生（自分専用）・生徒・応援団（資金援助者）のためのオンライン家庭教師アプリです。
Next.js (App Router) + TypeScript + Prisma + SQLite + Tailwind CSS で構築。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 役割分け | 先生用 / 生徒用 / 応援団用の画面を分離（ログインで自動振り分け） |
| チャット | 先生 ⇄ 生徒のリアルタイム風チャット（生徒ごとのスレッド、3秒ポーリング） |
| 問題画像の共有 | 授業ごとに作成。先生・生徒どちらからでも画像の追加/削除が可能 |
| 予約ポイント | 1pt = 30分。生徒が事前に購入し、予約時に消費（長さ/30分） |
| 決済 | パック購入 → 決済ページ（プレースホルダ）→ 完了でポイント付与。実決済は後で接続 |
| 授業可能枠（窓） | 先生が「授業できる時間帯」を登録。生徒はその中から予約 |
| 予約 | 生徒が科目・開始時間・長さ（30分単位）を選んで予約。誰が予約したか自動で記録 |
| 自動で埋まる | 予約された時間は他の生徒には選べない（重複はトランザクションで安全にブロック） |
| ビデオ通話URL | 予約確定時に自動生成（既定は Jitsi Meet のユニークルーム。`src/lib/video.ts` で差し替え可能） |
| カレンダー | 先生は授業スケジュールを月表示のカレンダーで確認 |
| 生徒メモ | 先生が生徒の特徴・習熟度を逐一メモ（授業中も時間外も追記・編集可。生徒には非公開） |
| 授業カンペ | 先生が事前に作る再利用ライブラリ。授業中に各授業ページから参照 |
| まとめノート | 先生が作成して生徒に公開。生徒はいつでも閲覧（チャットとは別） |
| フィードバック | 授業後に先生・生徒の双方から送信・閲覧（任意で5段階評価） |
| 成績 | 生徒がテストの点数・内申点を入力。先生はいつでも閲覧可能 |
| 応援団へ報告 | 先生・生徒が「最近がんばってること・勉強の状況」のエピソードを投稿。応援団はそれを一覧で閲覧 |
| 応援する（課金） | 応援団が支援プランを選んで資金援助できるページ（決済システムは現在プレースホルダ） |

## セットアップ

```bash
npm install
npx prisma migrate dev --name init   # DB作成（初回のみ）
npx tsx prisma/seed.ts               # 初期アカウント投入
npm run dev                          # http://localhost:3000
```

### 初期アカウント

| 役割 | ユーザー名 | パスワード |
| --- | --- | --- |
| 先生 | `teacher` | `teacher123` |
| 生徒 | `student` | `student123` |
| 応援団 | `supporter` | `supporter123` |

生徒アカウントは先生画面の「生徒・成績」からも追加できます。

## 使い方の流れ

1. **先生**でログイン → 「予約枠」で授業できる時間帯（窓）を追加。「カンペ」で授業カンペを事前作成
2. **生徒**でログイン → 「ポイント」でパックを選び決済（プレースホルダ）→ ポイント付与
3. 「予約する」で窓を選び、科目・開始時間・長さ（30分単位）を指定して予約（ポイント消費・ビデオURL自動発行）
4. 授業ページで問題画像を共有・ビデオ通話に参加。先生はカンペと生徒メモを参照しながら進行
5. 授業後、双方からフィードバックを送信。先生は「まとめノート」を投稿 → 生徒は「ノート」で閲覧
6. 生徒は「成績入力」でテスト点数・内申点を記録 → 先生は「生徒・成績」「カレンダー」で確認
7. 先生・生徒は「応援団へ報告」で最近がんばってることや勉強の状況を投稿 → **応援団**でログインすると一覧で閲覧できる
8. **応援団**は「応援する」から支援プランを選び、資金援助の手続きに進める（決済はプレースホルダ）

## 決済システムの接続（後で実装）

決済は現在プレースホルダです。実際の決済（Stripe等）を接続する際は、決済完了の通知を
**ポイント付与**につなぐだけで動きます。

- 付与処理: `src/lib/points.ts` の `creditPoints(userId, points, "PURCHASE")`
- 受け取り口（用意済みのスタブ）: `POST /api/payments/webhook`（`src/app/api/payments/webhook/route.ts`）
  - 本番では署名検証と決済イベントIDによる二重付与防止を必ず実装してください
- パック定義: `src/lib/packs.ts`（ポイント数・価格を編集）
- 現在の擬似決済ボタン: `src/app/student/checkout/`（実決済画面に差し替え）

## 技術メモ

- **認証**: HMAC 署名付き Cookie セッション（`src/lib/auth.ts`）。本番では `.env` の `SESSION_SECRET` を必ず変更してください。
- **DB**: SQLite（`prisma/dev.db`）。スキーマは `prisma/schema.prisma`。
- **予約モデル**: 先生の `Slot`（授業可能な窓）の中に、生徒の `Lesson`（科目・開始・長さ）を予約。重複・範囲外・ポイント不足は `src/lib/booking.ts` のトランザクションでまとめて検証。
- **ポイント**: `User.pointsBalance` に残高、`PointTransaction` に履歴（購入/消費/返却）。
- **画像**: base64 data URL として DB に保存（最大約4MB/枚）。
- **ビデオURL**: `VIDEO_BASE_URL`（既定 `https://meet.jit.si`）配下にユニークなルーム名を生成。Zoom 等に変える場合は `src/lib/video.ts` の `generateVideoUrl` を差し替え。

## 環境変数（`.env`）

```
DATABASE_URL="file:./dev.db"
SESSION_SECRET="（本番では長いランダム文字列に変更）"
VIDEO_BASE_URL="https://meet.jit.si"
```
